# Отель «Полночь»

Короткий пиксельный детектив ко дню рождения Инны. Три сцены, 15 наград и финальное поздравление.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень публичного репозитория. `index.html` должен находиться рядом с `README.md`, а изображения и музыка — в папке `assets`.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**.
4. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь завершения публикации. Готовая ссылка появится на этой же странице.

Посетителям сайта вход в GitHub не нужен.

## Игра

Подготовьте 15 штук шок милка и набор Zielinski & Rozen. Каждая награда на экране — сигнал вручить одну штуку молока. Набор вручается после кнопки «Получить подарок».
